# homelab-rclone

Private tool used only by me to back up my own home servers to my own Google Drive.

## Privacy policy
This app is used by a single person (the owner). It accesses only the owner's Google Drive, solely to upload and manage the owner's backup files. No data is collected, shared, sold, or sent anywhere other than the owner's own Google Drive.
